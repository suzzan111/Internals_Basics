# Internals_Basics

MLOps Lab CIE submission (DrillSense drilling-rate workflow).

## Project layout

All lab code, data, and proof JSON live under **`MLOps_Lab_CIE/`**:

| Path | Purpose |
|------|---------|
| `MLOps_Lab_CIE/data/` | `training_data.csv`, `new_data.csv` |
| `MLOps_Lab_CIE/src/` | `train.py`, `predict_cli.py`, `register_model.py`, `retrain.py` |
| `MLOps_Lab_CIE/results/` | `step1_s1.json` … `step4_s8.json` (machine-readable outputs) |
| `MLOps_Lab_CIE/models/` | Saved champion model (generated by `train.py`; not always in git) |
| `MLOps_Lab_CIE/requirements.txt` | Python dependencies |
| `MLOps_Lab_CIE/Dockerfile` | Task 2 container (`drillsense-predictor:v1`) |

## Run order (from `MLOps_Lab_CIE/`)

```bash
python -m pip install -r requirements.txt   # or use a venv
python src/train.py
python src/predict_cli.py --rock_hardness 0 --drill_bit_age_hours 0 --mud_pressure_psi 0 --depth_m 0 --write-step2-result
python src/register_model.py
python src/retrain.py
```
